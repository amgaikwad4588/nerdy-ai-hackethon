## Challenge Tracks (pick one or propose your own)
1. **K-5 Math Game** — interactive, gamified math experience for elementary students
2. **Language Learning App** — mobile experience using spaced repetition or immersive daily practice
3. **English Reading Game** — literacy-focused app for reading fluency and comprehension
4. **Open Category** — any genuine learning tool addressing a real learner problem

## Submission Requirements
- Project description (what it does, how it's built, next steps)
- Demo video (2–3 minutes; YouTube / Loom / Drive / Vimeo)
- Code repository (recommended)
- Live demo link (recommended)
- Name, email, and prompt/track selection

## Judging Criteria
- Educational rigor combined with engagement
- Real problem-solving for learners
- Quality of execution and demo-ability
- AI product engineering skills demonstrated
